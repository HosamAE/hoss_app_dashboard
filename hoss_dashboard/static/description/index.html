Hoss Dashboard

Turn the standard Odoo Home Menu into a beautiful, modern, fully customizable glassmorphism dashboard — no coding required.

🎨

Live Visual Customizer

Edit backgrounds, gradients, colors, spacing, icon shapes and card styles directly from the Home Menu, with instant live preview — nothing to configure through code.

✨

Glassmorphism & Presets

Choose from ready-made presets (Glassmorphism, Minimalist, Flat Material) or design your own theme: solid color, gradient or custom background image.

🖱️

Drag & Drop App Ordering

Users can reorder their app icons by simply dragging them, with the option for administrators to lock positions for a consistent company-wide layout.

🕒

Time-Based Themes

Schedule different dashboard themes to switch automatically by time of day — for example a bright theme in the morning and a darker theme in the evening.

🕐

Live Clock in the Navbar

Show an optional, fully styleable live clock and date in the top navigation bar, with adjustable colors, opacity, borders and shadows.

🔐

Granular Access Control

Administrators decide who can customize their own dashboard on a per-user basis, and can manage global or per-user themes from one central settings screen.

Personalize every pixel of the Home Menu

Greeting title & subtitle, alignment and font sizes, custom HTML welcome message, app icon size and shape, card background, opacity, border radius and more — all editable without touching a single line of XML.

How it works

1

Install the module — the Home Menu is instantly upgraded.

2

Click the paint-brush icon in the top bar to open the customizer.

3

Adjust colors, layout and content with live preview.

4

Save for yourself only, or apply the theme globally as an admin.

Compatible with Odoo 19 Community and Enterprise. No external dependencies.
